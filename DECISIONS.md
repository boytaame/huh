# Decisions & assumptions

- **Scaffold:** created Next.js manually instead of `create-next-app` because the workspace was not empty (`spec.md`). Pinned TypeScript 5.9 rather than the brand-new TS 7 for ecosystem safety.
- **First question auto-send:** §5.2 requires the first request to auto-send on release, while §5.3 calls a pre-send question field optional. I chose the instant path: the default question (`Explain this part step by step…`) is sent immediately and is also stored as the first user message so the thread/export is self-documenting. There is no blocking question dialog.
- **Persistence:** uses tldraw's `persistenceKey="ai-canvas-v1"` as instructed. In tldraw 5 this persists to browser-local IndexedDB under that key (older versions used localStorage). It is still purely local, with no database/auth.
- **Instant anchoring:** the region, thread and arrow are created before the PNG capture and network call. The blob shows "Looking at your selection…" while the crop is encoded, then streams. This keeps selection → blob feeling immediate.
- **Image capture:** `editor.toImage(shapesInSelection, { bounds, format: 'png', background: true, padding: 0, pixelRatio: 2 })`, then downscaled client-side to at most 1600px on the long side. The yellow selection shape and arrows are excluded from the capture. A visible background is kept so dark text is legible to the vision model.
- **Crop reuse:** the PNG is cached on both the `ask-region` (`imageDataUrl`) and the `ai-blob` (`regionImage`), as specified, and re-sent on every follow-up.
- **HTML shapes in captures:** tldraw's raster export skips HTML custom shapes. `AiBlobShapeUtil.toSvg` therefore renders a plain-text approximation (last few messages) so a child selection over an AI answer still contains text. The real parent thread messages are also sent in `ancestorContext`, so the model is not relying on the approximation alone.
- **Context budget:** `buildContext` uses a character budget (default 12,000 chars ≈ 3k tokens) rather than counting tokens. Board summary is capped at 2,000 chars, ancestor context at 3,000, and thread history is trimmed oldest-first. Full board JSON is never sent.
- **Ancestor chain:** walks up to 3 levels via `parentId`. AI parents contribute their last 3 messages; text materials contribute up to 1,200 chars; image materials are described by type/size. Regions terminate the walk.
- **Parent detection:** the Ask tool picks the topmost non-arrow/non-region shape whose bounds overlap at least 40% of the drawn selection. This lets a blob be a parent (child threads) without picking up previous yellow overlays.
- **Placement:** tries right of the selection (80px gap), then below-right, below, left. Chooses the first collision-free candidate that is mostly visible in the viewport, falling back to the least-bad candidate. Arrow endpoints are bound to the region's right edge and the blob's left edge with `isPrecise: true`.
- **Streaming ownership:** streaming lives in `lib/stream.ts`, not in the React component, so panning/culling a shape does not abort the request. Store updates are throttled to ~55ms, and a stream is abandoned if its blob is deleted.
- **Retry:** the last request payload is retained per blob. Retry drops the failed assistant placeholder and re-sends the same payload, so history is not duplicated.
- **Export scope:** nodes include `image`, `text`, `ask-region` and `ai-blob` shapes only, matching the schema in §5.5. Other tldraw shapes (geo, draw, note, frames) are not exported. Edges come from native arrow bindings (start → end); parent links live in each node's `parentId`.
- **`getBoardContext()`** returns the board JSON and is exposed on `window` for debugging; prompts use the much smaller `buildContext` output instead.
- **UI chrome:** tldraw's default main menu and page menu are hidden (single-page board, no accounts). The title and Ask controls are custom overlays; exports live in tldraw's native top-right `SharePanel` slot so they never collide with the style panel.
- **Provider defaults:** Gemini 2.5 Flash, Claude Haiku 4.5, GPT-4o mini. All are overridable via `LLM_MODEL`; provider code is confined to `lib/llm.ts`.
- **No extra features:** no auth, DB, sync, OCR, PDF import, study modes, mobile tuning or billing, per §6.
